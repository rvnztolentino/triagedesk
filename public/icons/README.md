# TriageDesk Icons

These files are generated from `public/icons/triagedesk.png` and should stay in sync with the shared in-app `BrandIcon` image source.

Current icon outputs:

- `public/favicon.ico` - browser favicon bundle.
- `public/icons/triagedesk.png` - 720x720 shared app/logo source served by `BrandIcon`.
- `public/icons/favicon-16x16.png` - 16x16 browser favicon.
- `public/icons/favicon-32x32.png` - 32x32 browser favicon.
- `public/icons/apple-touch-icon.png` - 180x180 iOS home-screen icon.
- `public/icons/icon-192x192.png` - 192x192 PWA icon.
- `public/icons/icon-512x512.png` - 512x512 PWA icon.
- `app/icon.png` - 720x720 Next.js app icon fallback.
- `app/apple-icon.png` - 180x180 Next.js Apple icon fallback.

Keep replacement artwork square and readable at 16x16.
